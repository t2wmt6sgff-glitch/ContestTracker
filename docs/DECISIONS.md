# Decisiones

Este archivo registra decisiones duraderas. No es un historial de cada cambio.

## D-001 — Producto local-first

**Estado:** aceptada

Los flujos principales de concursos, fases y repertorio deben funcionar sin cuenta ni conexión. Las funciones conectadas complementan el producto; no controlan el acceso a los datos básicos.

## D-002 — Web como canal público

**Estado:** aceptada

La futura web/PWA será el canal público principal mientras la app nativa no tenga distribución mediante App Store. Un IPA publicado en GitHub seguirá siendo un artefacto técnico sujeto a firma e instalación, no una distribución universal.

## D-003 — Backend condicionado a casos de uso

**Estado:** aceptada

No se elige proveedor ni se añade backend antes de identificar una historia de usuario que requiera servidor y definir privacidad, propiedad de datos, coste, offline y recuperación.

## D-004 — Una sola fuente de verdad del proyecto

**Estado:** aceptada

El repositorio contiene el contexto duradero: `AGENTS.md`, documentación, decisiones, código e historial. Los proyectos y chats de ChatGPT sirven para explorar y coordinar; las conclusiones que deban sobrevivir se trasladan al repositorio.
